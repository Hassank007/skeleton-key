Visual redesign of apps/grimoire only. Follow .kiro/steering (accessibility.md is non-negotiable). The hooks in .kiro/hooks/ are live. The behaviour is finished and tested; this batch changes how it looks. Read first: src/tokens/*.css, src/index.css, every file in src/components and src/pages, tests/unit and tests/e2e (catalogue, responsive, motion, book-detail).

GOAL: today the filters fill the first screen, the books start below the fold, and each book is a brown box with a small icon. Make it a candlelit library: cloth-bound covers standing on real shelves, visible in the first screen, with compact filters beside them, and a book page that looks like an open book. Same palette (parchment and crimson in light, near-black brown and amber in dark), same serif headings. It must not look like Seance (no ticket, no portraits, no rail).

TARGETS I measured on a mock-up of this spec: at 1440x900 and 1280x720 the first shelf starts about 270px from the top, with at least four covers fully visible; at 375x812 the first book starts above 812px.

- The set of --color-* tokens and their values (theme-identity and token tests). No hex, rgb(), hsl() or named colours in any component CSS (no-hex-in-components test). Where a mix is needed use color-mix(in srgb, var(--color-a) N%, var(--color-b)) on ONE line.
